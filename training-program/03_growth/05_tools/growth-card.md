# GROWTH Card — card bỏ túi (in ra, dán bàn)

> In 2 mặt, cỡ danh thiếp hoặc A6. Mở ra mỗi khi gặp một vấn đề khó.

---

## MẶT TRƯỚC — 6 bước

```
┌───────────────────────────────────────┐
│  GROWTH — dừng lại trước khi phản ứng  │
│                                         │
│  G  Outcome thật là gì?                 │
│     (không phải "task nào cần xong")    │
│                                         │
│  R  Fact là gì?                         │
│     (tách khỏi assumption & cảm xúc)    │
│                                         │
│  O  3 options + đề xuất của tôi         │
│     (không dừng ở "không làm được")     │
│                                         │
│  W  Ai — làm gì — trước khi nào         │
│     (còn trong Decision Rights không?)  │
│                                         │
│  T  Outcome đạt chưa? (đo, đừng cảm tính)│
│                                         │
│  H  Learning + chuẩn hóa gì cho team    │
└───────────────────────────────────────┘
```

---

## MẶT SAU — 3 câu tự cứu

```
┌───────────────────────────────────────┐
│  KHI BÍ, HỎI 3 CÂU:                     │
│                                         │
│  1. Phần nào việc này TÔI kiểm soát được?│
│                                         │
│  2. Đây là workaround hay permanent fix?│
│                                         │
│  3. Việc này còn trong quyền của tôi,   │
│     hay cần báo / xin ý kiến?           │
│                                         │
│  ─────────────────────────────────────  │
│  Báo vấn đề?  → luôn kèm ≥2 options     │
│  Thấy risk?   → escalate trong 24h      │
│  Đóng issue?  → có RCA chưa?            │
└───────────────────────────────────────┘
```

---

## Phiên bản 1 dòng (dán màn hình)

> **Có vấn đề → dừng lại → Goal → Fact → Options → Hành động (trong quyền) → Đo → Học.**

---

## Khi nào dùng card này
- Trước khi trả lời "không làm được" / "không kịp".
- Trước khi báo vấn đề cho Leader.
- Trước khi tự tay đổi một logic/scope.
- Trước khi đóng một issue production.
- Khi nhận một feedback làm mình khó chịu.

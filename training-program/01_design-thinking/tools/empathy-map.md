# Công cụ — Empathy Map

> Điền cho **một người dùng cụ thể** (RM / teller / cán bộ duyệt / khách SME), không phải "người dùng" chung chung.

```
Người dùng: ____________________   Bối cảnh: ____________________

┌───────────────────────┬───────────────────────┐
│  NÓI GÌ                │  NGHĨ GÌ              │
│  (câu họ thật sự nói)  │  (điều không nói ra)  │
│                        │                       │
├───────────────────────┼───────────────────────┤
│  LÀM GÌ                │  CẢM NHẬN GÌ          │
│  (hành vi quan sát)    │  (lo lắng / mong đợi) │
│                        │                       │
└───────────────────────┴───────────────────────┘

PAIN (khổ vì gì):        ______________________________
GAIN (muốn đạt gì):      ______________________________
```

## Cách dùng
1. Chọn 1 người dùng thật, 1 bối cảnh cụ thể (vd: cán bộ duyệt lúc 4h chiều, nhiều hồ sơ tồn).
2. Điền từ **quan sát/phỏng vấn thật**, không từ tưởng tượng.
3. Phần "Nghĩ gì" + "Cảm nhận" thường lộ ra nhu cầu ẩn — chú ý chỗ lệch giữa "Nói" và "Làm".
4. Từ Pain/Gain → viết Problem Statement (dùng [hmw-card.md](hmw-card.md)).

## Mẹo
- Một câu hỏi mở tốt: *"Kể cho mình nghe lần gần nhất anh/chị làm việc X — bắt đầu từ đâu?"*
- Nghe cái họ **than phiền** và cái họ **tự chế cách lách** — đó là mỏ vàng pain point.
